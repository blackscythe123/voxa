Voxa for Android, redesigned

Same brand as the desktop app (paper, sepia ink, the Fraunces wordmark), rebuilt as a real phone app: four tabs at the bottom, one clear job per screen, and the ink line Voxa draws while you talk as the one signature element.

Everything the current app does is here: setup, sign-in, the keyboard, History with playback, copy, edit, send again and delete, Words, every setting, and a week of numbers. The keyboard itself gets the same look, in light and dark.

One moment, under a second: the ink line writes itself, the wordmark settles, Home takes over. Loops here so you can watch it.

How it's built

Android 12 and newer show the app icon first (the system splash screen). Voxa then draws its own line on the same paper colour, so the handover is seamless, and the line ends where Home's practice pad begins.

It plays on a cold start only, never when you come back to an open app, and it's skipped when Android's "Remove animations" setting is on. It's a single vector path, so it adds nothing to the app's size or memory.
