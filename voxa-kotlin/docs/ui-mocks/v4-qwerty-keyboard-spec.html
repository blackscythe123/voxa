Voxa · v4 QWERTY + mic IME

Adds a second keyboard variant that is a normal QWERTY (with emoji, number row, punctuation, all the standard pieces) plus a small mic button in the top bar — just like Gboard. Tap the mic to record, tap again to stop, transcribe, and insert at the caret. While the mic is idle, the user can keep typing as usual. The existing VoxaInputMethod (voice-only) stays available; both show up in the Android keyboard picker so the user can pick whichever fits the moment.

Foundation

Fork of FlorisBoard (Apache 2.0, Kotlin + Jetpack Compose, very active). Reasoning is in docs/keyboard-survey.md — short version: it's the only candidate that matches Voxa's stack (Compose), ships under a permissive license, and lets us add the mic button as a single Composable in the smartbar. Trade-off: word suggestions / autocorrect are missing until upstream v0.6; emoji, number row, themes are all there today. If autocorrect becomes a blocker before v0.6 lands, fallback is to swap the keyboard layer to AnySoftKeyboard (Apache 2.0, full feature set, Java/Views — clashes with the rest of Voxa's stack).

The Voxa mic button is the only thing we add to the foundation. The keyboard chrome itself we leave alone so upstream merges stay easy.

Interaction notes

  • Mic tap = toggle. First tap starts recording; second tap stops, transcribes, inserts at caret. No long-press required — matches Gboard's mic, not Voxa-original's hold-to-talk.
  • Keys are live while recording. The user can keep typing on QWERTY during recording; the keyboard rows stay enabled. The top bar swaps suggestions for the recording banner so the suggestions strip doesn't compete for attention.
  • Transcribing state. Mic becomes a spinner; banner says "Transcribing…". On finish, the transcript is inserted via InputConnection.commitText at the caret, and the banner reverts to suggestions. On error, banner flashes red for ~2s then reverts.
  • Emoji panel. Lives behind the 😊 key in the bottom row. Standard FlorisBoard emoji grid — no Voxa changes needed there.
  • Session expired. If TranscriptionApi.validateSession() returns false on first tap, banner shows "Sign in to Voxa to dictate" with a tap-to-open-app link. Recording does not start. Keys still work.
  • Settings. Voxa's existing Settings screen gets one extra row in the Keyboard section: a switch to enable/disable the QWERTY variant. Disabled by default; user opts in.
