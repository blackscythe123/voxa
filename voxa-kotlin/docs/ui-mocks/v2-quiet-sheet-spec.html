Auth. what changed
  • WebView is now edge-to-edge. The full ChatGPT login page is shown including email field, Continue button, Google · Microsoft · Apple SSO buttons, and legal links. same as the real chatgpt.com/auth/login.
  • Voxa branding is reduced to a thin top strip (wordmark + "Connect ChatGPT" crumb + close button) so the screen reads as one integrated experience, not "our app wrapping a tiny web view".
  • Bottom progress strip shows live status (spinner + "Waiting for sign-in" → "Capturing session…" after redirect). Replaces the previous "Having trouble? Tap to retry" floating link.
  • When session capture completes, a capture-card overlay appears centered (semi-transparent backdrop, ring spinner, mono cookie names). confirms what's happening so it doesn't feel like a hang.
  • Google / Apple / Microsoft redirects happen inside the WebView (real OAuth flow). We snag the session cookie on the post-redirect `chatgpt.com` URL. No change to cookie-capture logic.

  • userAgentString spoof (Chrome on Pixel 8). keeps the Cloudflare bypass.
  • CookieManager.setAcceptThirdPartyCookies. required for Google/Apple/MS SSO.
  • tryCaptureSession(url) polling. same logic, just relocated to the bottom progress strip.
  • setSessionCookie() and setCookieHeader(). both still written (legacy single token + full cookie incl. cf_clearance).

IME. Wispr-flow waveform behavior
  • Idle: small dark mic disc (60dp), placeholder hint, monospace counter at 00:00. Delete + Space pill-buttons flank the mic.
  • Recording: mic turns coral-red with a white square (rec icon). Status dot pulses. Live waveform replaces the placeholder. The wave responds to your voice amplitude in real time. Compose-side polls MediaRecorder.getMaxAmplitude() every ~50 ms, normalises log-scale, pushes into a 96-sample ring buffer, and a Custom View draws two layered Bézier-smoothed strokes (primary ink-blue + softer trailing) that scroll right-to-left like Wispr Flow.
  • Tap mic again → Sending state (blue mic + spinner). Transcribe via existing TranscriptionApi.transcribeAudio(). Insert text into the active text field via currentInputConnection.commitText().
  • After insert → Voxa calls switchToPreviousInputMethod() (API 28+) so the user's previous keyboard (Gboard / SwiftKey / whatever) is restored. Fallback: requestHideSelf(0) + open input-method picker.
  • Done button (top-right of the bottom hairline strip when idle) also calls switchToPreviousInputMethod() directly. for users who opened Voxa but don't want to dictate.
  • Long-press mic → cancel/abort current take, no insert, no keyboard switch.
  • The Cancel + Send pill buttons during Recording give an explicit alternative to "tap mic again". useful when amplitude is jittery or the user wants to abort mid-recording.
IME. feature checklist (implementation)
  • Custom WaveformView extending android.view.View with onDraw(Canvas). Path with cubic Béziers, double-buffered ring buffer.
  • Amplitude poll loop: Handler.postDelayed every 50 ms → recorder.getMaxAmplitude() → push to buffer → view.postInvalidate().
  • Counter ticker: separate 100 ms loop updating "MM:SS / 02:00".
  • Auto-stop when counter hits prefs.getMaxDuration().
  • Switch-back: switchToPreviousInputMethod() in finally after commitText() succeeds. Fail-safe: if returns false, call imm.showInputMethodPicker().
  • Long-press on mic: setOnLongClickListener → cancel recorder, no transcribe.

4 · App icon · six options · monochrome

White ground, black mark. No mouth. Each shown rounded-square (Play Store), round (adaptive), small (in-app)

Six options, all monochrome. White ground (#FFFFFF), ink-black mark (#16161A). Each gestures at voice through sound, vibration, or the Latin V (vox = voice) without using a mouth glyph. The recommended pick is A · Wave V: five sound bars whose heights trace the V envelope, so the mark literally is voice forming the brand letter.

A · Wave + VOXA (Recommended)recommended

Six sound bars at the top (decorative waveform, not a letterform substitute) with VOXA set in Geist 800 Extra-Bold underneath. The wave reads as "voice", the wordmark reads as the brand. Both elements coexist instead of cleverly merging — simpler at small sizes, no ambiguity.

B · Monogram Vletterform

The letter V as one bold stroke with rounded caps. Direct Latin reference (vox = voice). Quietest, most letterform-driven mark. Could be mistaken for a generic V.

C · Sonic pulsebroadcast

A point with two concentric rings, sound projecting outward. Pure abstract symbol for vocal emission. Risk: reads as podcast or AirDrop to some users.

D · Sound traceoscilloscope line

A single flowing waveform stroke. Visual rhyme with the IME's live wave. The mark and the product show the same gesture, which is rare and memorable.

E · Tuning forkvibration source

A tuning fork. The original physical source of pitch. Pure-tone vibration symbol, also vaguely reads as a U/V hybrid. Quietest sound-source metaphor.

F · Whisper Vconcentric layers

Three nested V strokes fading inward. Reads as ripple, echo, or whisper. Letterform + sound-decay combined.

The narrative
  1. Stage 1 (0 to 1000ms) — Voice. Nine bars dance with audio-like amplitudes, centered on the screen. The screen is live voice.
  2. Stage 2 (1050 to 1600ms) — Bars form the V. The same bars rearrange. They drop to a baseline and their heights resolve into a V outline: tall edges, short middle. The wave becomes the letter V, but the bars themselves are what form it. Nothing fades, nothing is replaced.
  3. Stage 3 (1700 to 2300ms) — V slides. The bar-V translates left, into the wordmark's V position.
  4. Stage 4 (2000 to 2450ms) — OXA joins. OXA fades in tight against the V's right edge. ~5px gap. Full VOXA wordmark visible.
  5. Stage 5 (2450 to 2700ms) — The promise. "dictate anything from anywhere" fades in under the wordmark. Handoff.
Android implementation
  • One Canvas composable draws all 9 bars. Each bar has two values: height and y. animateFloatAsState on each (or updateTransition with a sealed-class state machine: Live, VShape, Settled).
  • Stage 1: amplitude state with 5 random frames every 170ms. Centered y formula: y = -h/2.
  • Stage 2: target heights = V_SHAPE constant, y formula switches to bottom-anchored: y = baseline - h. Compose interpolates both attributes smoothly.
  • Stage 3: animateOffsetAsState on the Canvas's Modifier.offset shifts the whole wave group left.
  • Stage 4 to 5: AnimatedVisibility with fadeIn + slideInHorizontally(8dp) for OXA, fadeIn for the tagline.
  • Wrap everything in SplashScreen.setKeepOnScreenCondition while the cookie validates. Skip stages 3 to 5 if validation completes during stage 1.
