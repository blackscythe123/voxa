Voxa v6, Manuscript ink

One theme, rebuilt from the EGM critique (docs/rebuild/02-ui-critique-v5.md). Fraunces and Instrument Sans on warm paper; a dark ink strip that holds its own over any app; ink is the action colour and red is kept for recording and errors only. The strip has four layouts, never shows a badge, always has one action and a way to close it. The quill is a system: it writes while you talk, keeps writing while the text is made, and signs off when it lands.

What changed from v5 (from the critique)

  • One theme instead of three re-skins. Ink is the action colour; red only for recording and errors (v5's C made every action look like an error).
  • Strip: 4 layouts. No badges; a fixed glyph slot (shape, not just colour); exactly one action; a close on every state that waits for you. Added Retry, mic blocked, ChatGPT unreachable (split from offline), and the timeout path. "Paste in Slack" instead of "Paste here"; "Cancel" instead of a bare ×; "Sign in to ChatGPT".
  • The quill is a system: live line from the mic level, a real nib pointing the way it writes, keeps writing while working, signs off when done.
  • Hub: tray dot + one window. Status headline comes from readiness ("Almost ready, one thing to fix"), only failing rows are shown, the rest collapse into one line. Not-sent items pinned on top with their one action. History reads as a written page, Copy only. Privacy line. Removed: stats, language chips, search, sidebar, Paste again, Shortcuts page.
  • Android: same layouts as desktop, same words; 48dp targets; ink line has a minimum width; Home is a setup checklist that becomes History. Removed: Today stats, Ready pill, Undo, Insert last.
  • Deferred: Undo after paste, change mic from the strip, language choice, stats, search.
