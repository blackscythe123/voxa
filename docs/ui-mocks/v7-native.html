Voxa v7: native screens

Each platform drawn with its own design system so it reads like a shipping app, not a prototype. Android uses Material 3 components, Roboto and Material Symbols on a Pixel-sized screen with a real keyboard. Windows uses Windows 11 Fluent: Segoe UI Variable, Segoe Fluent Icons, a native title bar, NavigationView, settings cards and an InfoBar. Voxa's identity rides on top: the sepia ink colour scheme, the Fraunces wordmark, and the ink line while you talk. Flow and states are unchanged from v6.
