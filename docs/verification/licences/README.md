# Open source licences: verification (2026-11-28)

Settings, Open source licences on both apps, generated by `tools/licences/generate.py` and guarded
by the `licences` lint group (docs/guardrails.md, section 11).

## What is listed

| App | Components | Distinct licence texts | Data in the app |
| --- | --- | --- | --- |
| Windows desktop | 418 | 295 | `licences-windows.json.gz`, 101,912 bytes embedded (1.18 MB of text) |
| macOS desktop | 423 | 301 | `licences-macos.json.gz`, 108,411 bytes embedded |
| Android | 184 (105 Rust crates incl. std, 78 Android libraries, Manrope) | 79 | `licences.json.gzip`, 24,063 bytes in the APK |

`THIRD_PARTY_NOTICES.txt` has all 567 components and their per-app summary by licence.

Licences found: MIT, Apache-2.0 and dual MIT/Apache-2.0 for most crates; Unicode-3.0 (ICU data
crates), BSD-2-Clause, BSD-3-Clause, ISC, Zlib, Unlicense or MIT, BSL-1.0, CC0-1.0 (hexf-parse),
MPL-2.0 (uniffi, uniffi_core, uniffi_pipeline on Android; unmodified, source link in the entry),
OFL-1.1 (Fraunces, Manrope), MIT (ONNX Runtime with its third-party notices, Silero VAD model).
Every Android library is Apache-2.0 except JNA, which is Apache-2.0 OR LGPL-2.1-or-later and Voxa takes it
under Apache-2.0 (the entry says so). One licence outside the owner's list: webpki-roots,
CDLA-Permissive-2.0 (Mozilla's root certificates as data, permissive), on the allow-list with the
reason. No GPL, AGPL, LGPL-only, SSPL or unknown licence ships.

Android release arm64 APK: 5,846,557 bytes before, 5,871,531 after (+24,974 bytes), budget 6.0 MB.
First try stored the data as `licences.json.gz`: the Android build unpacks `.gz` assets, so the
APK held 47 KB of deflated JSON under another name and the page could not open it. The instrumented
test caught it; the asset is now `.gzip`.
